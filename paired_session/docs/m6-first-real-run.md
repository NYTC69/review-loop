## Caps (M6-c)
`--help` defaults: `--max-plan-rounds 3`, `--max-exec-rounds 4`, `--max-invocations 25`, `--timeout 2700`, `--exec-turn-timeout` max(7200, timeout) capped at 14400. Pass all of these explicitly with `--author-vendor codex --reviewer-vendor claude --shadow on --adversarial-gate on --polish-round off`:

| Flag | M6 value | Why |
|---|---|---|
| `--max-invocations` | 18 | probe 2 + PLAN 2 rounds x 2 + EXEC 2 rounds x 3 (author, reviewer, shadow) + gate once = 13; a reviewer protocol retry per turn brings the worst case to 17; below 25. A hit is an abort |
| `--timeout` / `--exec-turn-timeout` | 1200 / 1200 | far below 2700 / 7200. Worst case 18 x 1200 s is 6 h, so the operator also stops at a 2 h wall clock (abort, no retry) |
| `--max-plan-rounds` / `--max-exec-rounds` | 2 / 2 | below 3 / 4 |

No `--resume-timeout`. `--lifecycle-mode` stays `off` (row 16). The run ends at DONE. `reject` is not part of M6 (it redispatches provider turns).

## Abort (M6-e)
Triggers: any unattributed global config change; escape sentinel; write outside the compass main checkout and `RUN_DIR`; model identity mismatch; cap hit; any non-triggered HOLD (reviewer HOLD, stale approval, allowlist change, uncertain turn) and any probe FAIL. No resume, no `--retry-uncertain`, no probe re-run. Findings visible only after the run mark the row FAIL. Procedure: Ctrl-C the coordinator; confirm the provider child exited using `state.active.pid` / `uncertain_active.pid` (or the receipt `pid`) as pgid; run `abort` with `EVIDENCE/args`; check `state.active` and `uncertain_active`; take the full after set of M6-d (all `before/` items) and verify the leftover BACKLOG hunk; preserve `RUN_DIR` and `EVIDENCE`; report. Never retry or rerun.
