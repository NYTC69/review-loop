## Rollback (R-f)
- Users: delete the `entry` key or set `entry: legacy`; `/review-loop:legacy` and natural-language "use the legacy review-loop workflow" (Codex) always force legacy. Routed runs never fall back on their own.
- Maintainer: `git revert` the merge commit of `audit/paired-session-next-batch` (and the release commit) on `main`, bump to 2.9.1 (a revert needs its own bump), push. Tag `v2.9.0` is never moved or deleted after push: fix forward with a new tag. Users pin the previous version by `plugin update` after 2.9.1.
- A misbehaving routed run is aborted with `paired-session abort`, its `run_dir` kept as evidence; it holds no commit, merge or push (lifecycle off).
